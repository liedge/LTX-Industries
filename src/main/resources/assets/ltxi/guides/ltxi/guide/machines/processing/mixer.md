# Mixer

<BlockImage id="mixer" scale="4" />

## About

This machine specializes in mixing chemicals, materials, and extracts that don't require the precision of a full
chemical lab system. It can also mix concrete, if you'd prefer that over our polymer panels.

## Recipe Spec

- Base crafting time: varies, by default 10 seconds
- Inputs: 0-4 items, 0-2 fluids
- Outputs: 0-1 items, 0-1 fluids
