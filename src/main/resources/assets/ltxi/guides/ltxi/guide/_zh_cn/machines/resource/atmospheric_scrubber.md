# 大气清洗器

<BlockImage id="atmospheric_scrubber" scale="4" />

## 概述

大气清洗器专用于从环境中提取气体和液体。 其可以设置为提取整个维度的环境资源流体，也可设置为提取特定局部地区（如主世界的海洋和沼泽）的资源。

## 属性

- 基础循环时间：30 秒
- 无需输入
- 输出：1\~4 种流体，0\~2 种物品
