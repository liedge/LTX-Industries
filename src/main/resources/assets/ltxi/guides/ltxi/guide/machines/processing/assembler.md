# Assembler

<BlockImage id="assembler" scale="4" />

## About

Our novice employees almost always learn the hard way that hand-crafting technology caps out rather quickly. Luckily,
the Assembler is capable of manufacturing almost every building block component such as voltaic cells, circuits, and
machine housings.

## Recipe Spec

- Base crafting time: varies, by default 10 seconds
- Inputs: 1-6 items, 1 optional fluid
- Output: 1 item
