# 配方模式

某些配方使用的原材料相同， 为避免配方冲突，模组引入&#x4E86;_&#x914D;方模式_。 其可以理解为配方小类，或是某种指定具体配方的“关键材料”。 配方模式可以在机器中手动切换，但&#x662F;_&#x975E;常建&#x8BAE;_&#x4E3A;每种配方模式安排一台专用机器， 只靠手动切换配方模式的话，可能会因为忘记切换，出现类似把一组电浆果误处理成了电浆绿颜料而非钠粉的麻烦事情。

## 选择

![](../assets/recipe_modes_button.png)

对于可选择模式的机器，左下方的侧边栏会出现配方模式选择按钮。 此按钮会显示当前模式的图标，鼠标指向时也会显示名称。

## 模式可用性

![](../assets/recipe_modes_screen.png)

每种配方类型（以及机器）最多可具有 23 种可选的配方模式，且第一个按钮总是保留为无模式。
可选的配方模式有两种来源，一是配方类型附带的默认模式，二是通过[升级模块](../fundamentals/upgrade_system.md)解锁的额外模式。 默认配方模式总是可用， 升级模块提供的配方模式需要相应模块保持安装，若相应模块被移除，则会重置为无模式。
